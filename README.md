# Ringkasan project
Project ASTQA ini bertujuan melakukan review kualitas dokumentasi SRS dan SDD pada aplikasi SISTER Web Sekolah menggunakan pendekatan Checklist-Based Review. Hasil evaluasi menunjukkan bahwa dokumentasi sistem sudah baik dan konsisten, tanpa temuan mayor, namun masih memerlukan beberapa penyempurnaan pada artefak dokumentasi seperti diagram UML, glossary, prioritas requirement, dan traceability agar lebih sesuai dengan praktik terbaik dalam Software Quality Assurance.
